LLM Matching — Claude API

Replaced the original scoring algorithm. A single Claude call handles vocabulary ambiguity, missing context, and construction slang — and returns a structured confidence score the Superintendent can trust.

Learning Loop

Every Superintendent decision is logged as a few-shot example and included in the next Claude prompt. The model learns the specific language patterns of this site and crew over time.
